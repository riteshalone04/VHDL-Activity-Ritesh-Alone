DESIGN & IMPLEMENTATION OF T FLIP-FLOP

Digital System Design using VHDL | Technical Activity 01

1. Abstract

The T (Toggle) Flip-Flop is a single-input synchronous sequential circuit used for 1-bit binary storage. It complements its internal state on every active clock transition whenever input T = 1. This design covers theoretical logic verification, VHDL behavioral modeling, simulation waveforms, and target synthesis for FPGA hardware architecture.

2. Objectives

  • Model a T Flip-Flop using VHDL behavioral architecture style.
  • Verify input-to-output logic state transitions via simulation.
  • Incorporate active-high synchronous reset control logic.
  • Synthesize circuit logic for Spartan-6 / Artix-7 FPGA boards.

3. Logic & Mathematical Model

Characteristic Equation:
Q(next) = T ⊕ Q = T·Q' + T'·Q

RESET CLK T Input Q (Next) State Operation
1 X X 0 Reset State
0 ↑ 0 Q No Change (Hold)
0 ↑ 1 Q' Toggle State

4. VHDL Behavioral Code

process(CLK, RESET) begin if RESET = '1' then q_reg <= '0'; elsif rising_edge(CLK) then if T = '1' then q_reg <= not q_reg; end if; end if; end process; Q <= q_reg; Q_BAR <= not q_reg;

6. Practical Applications & Characteristics

  • Frequency Division: Acts as a divide-by-2 frequency divider module in clock generation networks.
  • Binary Counters: Cascading T Flip-Flops forms asynchronous (ripple) and synchronous binary counters.
  • State Machine Controllers: Used in Finite State Machines (FSMs) requiring automated state toggling.
